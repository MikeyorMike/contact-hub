## 4. 推到 GitHub

仓库已经在本地初始化并有 8 次提交（`git log --oneline` 可查看）。创建远端仓库后执行：

```bash
git remote add origin https://github.com/<你的用户名>/contact-hub.git
git branch -M main
git push -u origin main
```

注意：

- [ ] 仓库设为 **Public**（老师要能访问）
- [ ] 不要提交 `data/`（已在 `.gitignore` 中）
- [ ] 推完在网页上确认提交次数 ≥ 3，且能看到 8 次提交
- [ ] 两位成员都用**各自的 GitHub 账号**提交过内容，博客里的「每人提交数」与 `git shortlog -sn` 一致
- [ ] 两个人都用自己的 GitHub 账号至少提交一次，方便统计「每人提交数」

## 5. 部署到云服务器（+15 分，强烈建议做）

1. 买一台最低配的云服务器（华为云 / 阿里云 / 腾讯云，学生机即可），系统选 Ubuntu 22.04；
2. 安全组放行 3000 端口（或 80）；
3. 按 `README.md` 的「部署到云服务器」操作；
4. 用手机流量（不要连 Wi-Fi）访问 `http://公网IP:3000`，能打开就说明真的部署成功了；
5. 把地址填进博客，**localhost 链接不算分**。

小提示：如果服务器在国内，80 端口需要备案，直接用 `IP:3000` 最快。

## 7. 常见翻车点

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 老师打开仓库是 404 | 仓库是 Private | 改成 Public |
| 博客图片裂开 | 用了本地路径或图床外链失效 | 用 CSDN 自带图床重新上传 |
| 部署地址打不开 | 安全组没放行 / 服务没守护 | `curl localhost:3000` 先自查，再查安全组 |
| 提交次数不够 | 只推了一次 | 按功能补提交，或把本地 5 次提交一起推上去 |
| 导入报「缺少姓名列」 | 表头不是模板格式 | 先下载空白模板再填 |
| 视频太大传不上 | 超过平台限制 | 压到 1080p、5 分钟内 |
