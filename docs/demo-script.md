# 演示视频分镜脚本（3–5 分钟）

> 建议用 OBS Studio（免费）或 Windows 自带「游戏录屏（Win + G）」录制，分辨率 1440×900 或 1920×1080。
> 录制前执行 `node scripts/seed.js` 重置数据，保证截图与视频里的数据一致。
> 视频上传到 B 站 / 网盘后，把链接填进博客第 4 节。

## 准备

1. 启动服务：`node server.js`，浏览器打开 `http://localhost:3000`。
2. 打开 `docs/sample-import.xlsx` 备用（演示导入）。
3. 缩小浏览器窗口到 1440 宽左右，隐藏书签栏，界面更干净。

## 分镜

| 时间 | 画面 | 操作 | 解说词 |
| --- | --- | --- | --- |
| 0:00–0:15 | 首页全景 | 不动 | 「这是轻contacts 通讯录，左边是视图和标签，中间是联系人列表，右边是详情。」 |
| 0:15–0:35 | 收藏功能 | 点某张卡片的星标 → 切到「收藏夹」 | 「点星标即可收藏，收藏夹里只显示重要联系人，排序时收藏也优先。」 |
| 0:35–1:05 | 多联系方式 | 点开「陈子墨」→ 详情页滚动 | 「一个联系人可以挂多条手机号、邮箱、微信、微博，主要号码有标记，右侧按钮可一键复制。」 |
| 1:05–1:45 | 新建联系人 | 点「新建联系人」→ 填姓名 / 公司 → 添加手机号、邮箱、微信 → 设主要 → 勾选收藏 → 保存 | 「联系方式可以随时增删，主要号码用来在列表里展示。」 |
| 1:45–2:05 | 搜索 | 搜索框输入「福大」或手机号 `13905910001` | 「搜索覆盖姓名、公司、标签、备注和所有联系方式；号码带不带空格都能搜到。」 |
| 2:05–2:45 | 导出 Excel | 点「导出」→ 打开下载的 xlsx | 「导出是一个联系人一行、每类信息一列，带表头样式和冻结首行，可以直接交给 Excel 处理。」 |
| 2:45–3:30 | 导入 Excel | 点「导入」→ 选 `docs/sample-import.xlsx` → 展示结果 | 「导入自动识别表头，逐行校验；重复的联系人（姓名 + 手机号相同）会跳过并列出原因。」 |
| 3:30–3:50 | 编辑与删除 | 编辑刚导入的联系人 → 删除 | 「编辑会整体替换联系方式，删除会级联清理，操作后列表和统计实时刷新。」 |
| 3:50–4:10 | 深色模式 / 移动端 | 点右上角主题切换；把窗口拉窄 | 「支持深色模式和移动端布局，窄屏下详情变成抽屉。」 |
| 4:10–4:30 | 结尾 | 切回首页 | 「代码与文档都在 GitHub 仓库，测试用 npm test 一键运行，谢谢观看。」 |

## 录制小贴士

- 不要录到通知弹窗；开「专注助手」。
- 鼠标移动放慢，点击后停顿 0.5 秒再继续。
- 视频开头加 2 秒标题页（项目名 + 姓名 + 学号），结尾加仓库地址。
- 导出后的 xlsx 建议用 Excel / WPS 打开并录进去，这是「导出成功」最直观的证据。
- 导入演示文件里已经内置了一条重复数据（林清和）和一条缺姓名的数据，正好展示跳过与失败提示。
